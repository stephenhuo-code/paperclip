# Contract: first-run.sh

## 调用

```sh
/opt/paperclip/deploy/scripts/first-run.sh <env>     # 例如 production，以 root 运行
```

## 交互顺序

| 步骤 | 已完成时 | 未完成时提示输入 |
|---|---|---|
| 0. 前置检查 | — | 无；平台或 Keycloak 未就绪则退出码 1，不做改动 |
| 1. Keycloak 全局管理员 | 显示"已存在"，跳过 | 用户名；密码（不回显，输入两次） |
| 2. Paperclip 管理员 | 显示其邮箱，跳过 | 姓名；邮箱；应急密码（不回显，两次） |
| 3. 公司 | 一家：显示名称并使用；多家：列出编号供选择 | 公司名称 |
| 4. 管理员企业账号 | 显示"已存在"，确保在组织中 | 企业账号密码（不回显，两次；不得与应急密码相同） |
| 5. 关联与关闭注册 | 显示"已完成"，不重新部署 | 无 |

步骤 1–4 的输入收集完后，先汇总将要执行的操作并询问 `确认执行？[y/N]`；回答非 `y` 则退出码 0，不做改动。

## 输出

- 每步一行结果：`created`、`exists, skipped`、`linked` 等。
- 结束时打印：Paperclip 地址、Keycloak 管理台地址、"员工请在 Keycloak 中添加并加入组织 <alias>"。
- 任何输出、日志、命令行参数中都不出现密码。

## 退出码

| 码 | 含义 |
|---|---|
| 0 | 完成，或用户取消 |
| 1 | 前置检查失败、某一步失败（已完成的步骤保留，可重新运行） |
| 2 | 重新部署失败并已回滚（沿用 `remote-deploy.sh`） |
